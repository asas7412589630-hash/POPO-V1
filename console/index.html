06 · GUIDE

使用說明

控制台保留 POPO V1 的精簡導覽，並整合 V2 管理功能。

快速開始

三步驟：① 填 Base URL 後按「讀取模型清單」（金鑰可留空，多數供應商不需金鑰就能列模型）。 ② 勾選要發布的模型，每個模型可各自選積木（四個非 GPT 家族共用 V1 Cinder 組合）。③ 需要時驗證金鑰、測一次對話，最後建立 POPO API。

多來源與路由

在「來源」新增相容的上游服務，取得模型、測試連線，並發布模型路由。模型 ID 可連到不同來源，管理員憑證用於來源與帳號管理。

使用管理

「金鑰」管理用戶端 API key 和帳號；「紀錄」包含對話、用量、稽核、回放、模型比較及資料保留；「調校」可讀寫執行參數並預覽破甲 profile。

相容 API

API base URL 使用設定頁顯示的網址。

POST /v1/chat/completions GET /v1/models GET /health GET /armor?model=&level= 支援 OpenAI 相容的 Chat Completions 與模型清單；串流、工具呼叫及供應商支援度依伺服器設定而定。
